# Une jeunesse au grand air

Aventure dont vous êtes le héros sur le premier tour du monde (1519-1522), pour la seconde (histoire, thème 2 : l'ouverture atlantique).

L'élève incarne Diego, fils de morisques, ou Inés, fille de conversos déguisée en garçon, mousses sur la flotte de Magellan.

Jouer : https://didagame.github.io/AVHmagellan/
